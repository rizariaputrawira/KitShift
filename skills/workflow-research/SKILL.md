# Research

1. Restate the research question, intended decision/use, scope, and authorized destination. Resolve discoverable context before asking; if no destination is specified, report findings in the response rather than silently writing into the repository.
2. Investigate authoritative primary sources (official documentation, standards/specifications, first-party API or source code). Trace each material claim to its owning source; distinguish direct evidence from interpretation, note dates/version applicability and unresolved conflicts. Use secondary material only to find or contextualize primary evidence, not as sole support.
3. Produce a concise report with question/scope, findings and inline links/citations adjacent to claims, relevant caveats, and remaining unknowns. Save to the requested or established local notes location only when authorized. A native background task may research an independent question when useful, but is optional; verify its source links and conclusions before incorporating. Do not claim a file was written or a source checked unless observed.
