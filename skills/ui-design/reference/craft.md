# Craft (deprecated alias)

`craft` is a legacy label for an ordinary request to make visual work, not a separate runtime command. It adds no setup, interview, checkpoint, tool or actor requirement. Follow [Workflow and authority](../SKILL.md#workflow-and-authority) and relevant design/implementation reasoning in [new-work.md](new-work.md). Missing PRODUCT.md/DESIGN.md or helper state does not require init or persistent workflow selection.

Do not tell users they need to invoke `craft`. Natural requests such as “build this feature,” “make a landing page,” or “redesign this screen” use the same flow.
