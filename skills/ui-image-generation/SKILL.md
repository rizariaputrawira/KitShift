# UI image generation

Modified integration of the Taste web/mobile image-generation procedures. Copyright
(c) 2026 Leonxlnx. Full [MIT notice](LICENSE.taste), [source mappings and modifications](SOURCES.md).

1. Establish the requested platform, brief, supplied assets, deliverable count and
   states. Do not infer additional screens, sections, product features or evidence.
2. Select exactly the relevant platform procedure: requested website sections use
   [web](references/web.md); requested mobile app screens or flows use
   [mobile](references/mobile.md). Load both only for an explicitly cross-platform
   request. Platform examples remain optional and subordinate to the brief.
3. Confirm an available, permitted image-generation tool before promising images.
   If unavailable, report the missing prerequisite and incomplete image deliverable.
   A text proposal is not a generated image or a successful tool result.
4. Follow the selected procedure within native authority. Preserve product/brand
   context and factual boundaries. Image-only requests do not authorize code,
   installation, publication, service startup or a platform conversion.
5. Return actual requested images and observed limits. Synthetic concepts are not
   screenshots of a real product, real customer evidence or implementation proof.

Implementing a supplied or permitted generated reference belongs to
skill://ui-image-to-code. General UI refinement belongs to skill://ui-design.
