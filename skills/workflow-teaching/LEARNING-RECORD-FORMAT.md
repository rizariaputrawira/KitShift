# Learning record format

Store sequential records under `learning-records/`, creating the directory only when the first record is authorized and warranted.

```md
# <Short learning or prior-knowledge statement>

<One to three sentences: evidence of what the user learned or already knew, and why it changes future teaching.>
```

Write a record for demonstrated non-trivial understanding, disclosed prior knowledge with its depth, a corrected misconception, or an agreed mission shift. Do not record mere coverage or duplicate glossary definitions. Optional evidence/status/implication details belong only when they add value. When contradicted, mark the older record superseded by the new record; never silently erase that history. Choose the next unused sequential number.
