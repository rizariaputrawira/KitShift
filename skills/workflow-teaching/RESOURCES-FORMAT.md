# Resources format

`RESOURCES.md` is a curated, annotated set of trusted sources aligned to the mission.

```md
# <Topic> Resources

## Knowledge
- [<Source>](<URL>) — <What it covers and when to use it.>

## Wisdom (Communities)
- <Community or local group> — <What it is useful for.>

## Gaps
- <Needed topic without a trustworthy resource, if any.>
```

Prefer primary sources, recognized experts, peer-reviewed work, and well-moderated communities. Annotate every entry, expose gaps, and remove sources shown to be unreliable or off-mission. Respect stated preferences about communities.
