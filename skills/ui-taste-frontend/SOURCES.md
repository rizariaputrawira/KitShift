## Technical reference

[WCAG 2.2 Understanding Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) distinguishes normal text's 4.5:1 contrast from large text's 3:1; the large-text threshold is 18pt regular or 14pt bold, not 18px generally. This is a cited technical reference, not a compliance certification.

[Web Vitals](https://web.dev/articles/vitals) supplies the cited LCP/INP/CLS targets and 75th-percentile field-evaluation context. Lab evidence and field outcomes remain distinct; a Lighthouse run is not an INP result.
