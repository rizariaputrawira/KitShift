# Rejected-request knowledge base

When the repository maintains `.out-of-scope/`, it records durable rejected enhancement concepts for institutional memory and deduplication. One readable file per concept can capture rationale and prior requests. Treat matches as candidates for maintainer review, not automatic disposition. Bugs and already-implemented features do not belong in this rejection ledger. Update/create/delete these records only when explicitly authorized; preserve the repository's format and link the issue evidence. Do not assume this directory or convention exists.
